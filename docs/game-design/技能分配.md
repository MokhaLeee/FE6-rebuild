# 封印之剑 技能设计 v3

> 设计稿，不是实现记录。  
> 当前等级前提：等级上限 99，转职保留等级、经验清零，属性上限不变。  
> 核心原则：**技能 = 触发器 + 决策；学得多，带得少。**

## 1. 设计原则

1. **删除无决策技能**：第一回合 +3、常驻 +2、无条件 +10 命中这类全部不要。
2. **每人 1 个固定技能（签名）**：固定身份，不占装备槽；可在准备画面关闭，用于挑战 build。
3. **每人可学很多，进场只带 4~6 个**：学习池约 12 个，RAM 槽决定本关打法。
4. **组合靠动作顺序、站位、风险**，不靠同名数值叠加。
5. **敌人技能必须可读、可反制**：普通 1 个，精英 2 个，Boss 3 个；图标和名字可见。

## 2. 固定技能与 RAM 技能

固定技能（常驻，不占槽）：

- `J:` 职业固定 2 个，写 `gSkillJTable`；上位职业继承下位 1 个，再新增 1 个。
- `P:` 人物固定 1 个，写 `gSkillPTable`，即“签名”。

RAM 技能（可换，占槽）：

- 武器精通 4 个（C / B / A / S）
- 通用高阶 6 个（Lv30 / 40 / 50）
- 剧情/专属 1 个
- 学会 ≠ 生效；准备画面选 4~6 个带进场。

| 节点 | 解锁 |
|---|---|
| 加入 | 人物固定 1 + 下位职业固定 2 |
| Lv10 / 20 | 武器 C / B |
| Lv15 / 25 | 第 5 / 第 6 个 RAM 槽 |
| 转职 | 上位职业固定 2 + 人物固定强化 |
| 武器 A / S | 武器 A / S |
| Lv30 / 40 / 50 | 通用高阶 |
| 剧情 / 专属武器 | 专属技能 |

- 学习池约 12 个：武器 4 + 通用 6 + 剧情 1 + 签名强化；固定技能不计入。
- 实现：固定技能走 J/P 表；RAM loadout 独立存；`Unit.skills[]` 只放 loadout，战斗列表动态构建，不受 4 槽限制。
- 职业固定只做低强度基线，复杂机制放人物固定和 RAM 技能。

### 2.1 通用高阶（Lv30+）

| 节点 | 可学 |
|---|---|

## 6. 组合示例

| 组合 | 技能 | 玩法 |
|---|---|---|
| 冲锋骑 | `冲锋` + `再移动` + `疾风` | 远距离打一套，撤到安全格 |
| 护卫盾 | `守护` + `反震` + `壁垒` | 卡口，保护后排，诱导敌人攻击 |
| 火焰区 | `火焰继承` + `元素场` + `再动` | 封通道，逼敌人绕路或踩火 |
| 开局猎杀 | `猎首` + `标记` + `再动` | 第一回合点掉关键法师/弓箭手 |
| 飞骑阵 | `三角` + `空战` + `俯冲` | 三飞骑抱团，吃满阵型加成 |
| 敌后盗贼 | `偷窃` + `烟雾` + `逃脱` | 偷道具、开箱、全身而退 |

组合限制：同一角色最多 1 个再动、1 个伤害倍率、1 个守护类技能，避免叠满。

## 7. 敌方技能

| 敌人 | 技能 | 反制 |
|---|---|---|
| 先锋 | `突进`：移动 ≥3 后伤害 +20% | 诱饵、卡地形 |
| 盾兵 | `列阵`：相邻敌人防 +3 | 断阵、魔法、绕后 |
| 猎手 | `标记`：攻击后友军对其命中 +15 | 优先击杀、净化 |
| 术士 | `诅咒`：3 格内友军治疗效果 -50% | 沉默、冲脸 |
| 指挥官 | `号令`：2 格内敌人命中 +10、伤害 +2 | 斩首、分割 |
| Boss | `阶段`：HP 75/50/25% 时更换一个技能 | 看提示、换打法 |

- 普通敌人 1 个技能，精英 2 个，Boss 3 个；不随机、不隐藏。
- 敌人技能优先改变规则，不加纯数值：禁止治疗、改变地形、强制换位、反击姿态。
- 不给敌人“无条件先制/全屏 debuff/隐身必中”；所有强力效果必须有提示或代价。

## 8. 删除与保留

删除：

- 第一回合 +3、常驻 +2、无条件 +10 命中；
- 纯数值叠叠乐、同名技能重复生效；
- 90% 情况下不会触发的条件技能。

保留：

- 能改变站位的技能；
- 能改变行动顺序的技能；
- 有代价的爆发；
- 能保护队友或诱导敌人的技能；
- 每章一次的保命/逃脱类技能。

## 9. 实现顺序

1. 先填职业固定表 + 人物固定表 + loadout/准备画面技能页；不碰旧战斗公式。
2. 先实现 10~15 个通用技能，验证触发器、冷却、每回合一次。
3. 再做人物签名（每人 1 个），最后做敌人模板。
4. 旧文档的 55×5 人物等级表删除；旧技能名可复用，但必须按本稿重写触发条件。
