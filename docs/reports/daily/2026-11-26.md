### 地图治疗动画（fed30c8、74a4625、fbc84b3）

HealingFocus 之前只播 `StartStatusHealEffect()` 闪一下，hp 还是手工加的。它该长成伤药的
地图动画那样，但那条路走 `BeginBattleAnimations()`：需要 `gBattleUnitA` 快照（治疗量以
「负伤害」传递），伤药本身还要占一个道具槽，技能两样都没有。

- 新增 `StartMapHealAnim()` / `MapHealAnimExists()`：单位播「使用道具」的 Mu 姿势，hp 加上、
  治疗光辉绽放，调用方进程锁到动画结束；
- 光辉复用原版 `StartManimHealFx()`，它不读 `gManimSt`，脱离战斗动画也能跑；原本由 manim
  调用方负责的两件事在这里补上 —— 首帧以透明开始并预载调色板（fx 进程晚一帧才设混合），
  结束后用 `InitBmBgLayers()` 复位 BG 层；
- 74a4625 补 hp 槽：复用 `PutManimWindowBar()` / `PutManimWindowNumber()`（改成收 max/fill
  参数、不读 `gManimSt`），槽画在脚下偏一行，hp 每帧涨 1/4 点、每整点一声 SONG_75，
  拆场时归还 chr 槽与图标调色板；
- fbc84b3 把 HealAnim / masseffect 一起搬进 `src/Common/manim`，地图动画 API 从
  `include/hacks` 移出（不再属于技能）；顺手把只在本文件用的
  `BeginUnitHealAnim` / `BeginPoisonDamageAnim` 与 `ProcScr_StatusHealEffect` 子脚本改成
  static，删掉无人引用的 `ProcScr_Unused_KillAllRedUnits`。
