> 标注图：`ch1-map-design.png`。蓝=我方，红=初始敌人，虚线=增援，
> 青色箭头=主路推进，粉红箭头=湖西侧新路线。

## 1. 地图扩宽

原版 15x21 左侧被湖泊和悬崖封死。现在向西扩宽 3 列：

| 项 | 改动前 | 改动后 |
|---|---|---|
| 尺寸 | 15 x 21 | **18 x 21**（288 x 336 像素） |
| 相机 | 一屏宽，只能上下滚 | 可横向滚动（camera_max.x = 48） |
| 湖的位置 | x = 0..7 | x = 3..10 |
| 新区域 | 无 | x = 0..2 |

## 2. 西侧新列的地形设计

为了“美化、合理、符合地形预期”，新列不是一整块平原：

| 列 | 地形 | metatile | 作用 |
|---|---|---|---|
| x = 0 | 森林带 | 720/782/783/814 交替 | 地图西边界收边，避免草地被生硬裁断 |
| x = 1 | 草地 | 6/38/14 交替 | 可通行的主路 |
| x = 2 | 草地；湖段（y=7..15）用森林过渡 | 6/38/14 + 782 | 与湖岸悬崖之间用树林过渡，不直接“草地贴崖壁” |

湖东岸的悬崖（原 x=0 列）随地图右移到 x=3，保持原样，所以湖仍然被崖壁围住。

可通行性：

- x = 1..2 是平原，任何单位可通过；
- x = 0 是森林（可通行但消耗 2），作为视觉边界，不影响通行；
- 西侧通道宽 2~3 格，骑兵可以快速北上。

## 11. 美化迭代记录

- **湖岸**：原版 x=0 列的湖水/悬崖 metatile 是为“贴地图边界”设计的，右移到内部后会露出尖角。处理方式：用森林带（x=3，y=7..15）覆盖，湖的西岸变成林岸；湖的东/南岸保留原版悬崖。复查“水格直接贴草地/森林”的数量为 0。
- **地形层次**：
  - 西侧：x=0 森林带、x=1..2 草地路、x=3 湖岸森林；
  - 中部：森林 + 丘陵（(9,7)、(10,8) 等）；
  - 上/下/右：补了 (1,2)、(3,1)、(2,4)、(1,17)、(9,18)、(13,17)、(13,18)、(2,1)、(2,2)、(2,5) 等森林，以及 (11,12)、(12,13)、(13,6)、(14,6) 丘陵；
  - 统计：PLAINS 211 → 187，FOREST 53 → 81，MOUNTAIN 11 → 17。
- **湖湾**：湖的 (4,13) 附近保留一小块岸边水湾（水贴森林），当作自然水湾。
- 每次改动都用 `tools/maptools/render_chapter.py` 渲染检查，最后跑全量 emu 测试（39 通过）。
